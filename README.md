# RadioGo by infobit.cloud

Internet Radio Streaming App built with Flutter.

## Features
- 🎵 Stream thousands of radio stations worldwide via Radio-Browser.info API
- 🌐 IT + EN localization (GetX translations)
- 🎨 Cyberpunk / Matrix green terminal theme
- ⏯️ Background playback with lock screen controls (audio_service + just_audio)
- ❤️ Favorite stations with persistent storage (Hive)
- 🕐 Recently played history
- 🔍 Real-time station search with debounce
- 📡 ICY metadata parsing for track titles
- 📱 Marquee scrolling for now-playing info
- 🖥️ Matrix rain splash screen animation
- 🌙 Dark cyberpunk UI with glow effects

## Tech Stack
- **State Management**: GetX
- **Local Storage**: Hive
- **Audio**: just_audio + audio_service
- **API**: Radio-Browser.info
- **Fonts**: ShareTechMono + Orbitron

## Getting Started
```bash
flutter pub get
flutter run
```
